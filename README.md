# MyChatAgent

## Project Description

MyChatAgent is a simple AI-powered chat agent developed using Python and the OpenAI API. It accepts user questions and generates intelligent responses using an AI model.

## Features

- Interactive chat with an AI agent
- Accepts user input from the terminal
- Generates AI-based responses
- Uses the OpenAI API

## Technologies Used

- Python
- OpenAI API
- OpenAI Python SDK

## Project Structure

MyChatAgent/
├── main.py
├── requirements.txt
└── README.md

## Requirements

Python 3.x and the required packages listed in requirements.txt.

## Installation

pip install -r requirements.txt

## Running the Agent

python main.py

## Example

You: What is artificial intelligence?

Agent: Artificial intelligence is the ability of computer systems to perform tasks that normally require human intelligence.

## Conclusion

This project demonstrates how to build a basic AI chat agent using Python and the OpenAI API.
